Jag har en kandidatexamen i systemutveckling och drygt 20 år som egenföretagare bakom mig. Under de åren drev jag två verksamheter med ansvar för personal, ekonomi och daglig drift. Nu utbildar jag mig till moln- och virtualiseringsspecialist och har hittills fått VG i alla avslutade kurser.

Jag trivs bäst när jag får bygga och förvalta IT-miljöer som fungerar i vardagen för dem som använder dem. I skolan och i mitt hemmalabb arbetar jag med både on-prem och moln: Windows Server, Active Directory och Hyper-V lokalt, och Azure, AWS och Microsoft 365 i molnet. Från åren som företagare tar jag med mig vanan att ta ansvar, prata med kunder och lösa problem utan att göra dem krångligare än de är. Nu söker jag LIA-plats inom IT-drift, infrastruktur eller moln, där jag kan bidra från start och fortsätta lära mig.

Projekt

Egna projekt vid sidan av studierna. Jag står för idé, arkitektur, test och drift. Koden tas fram med AI-stöd.

  • On-prem-labb i Hyper-V

    Windows Server, Active Directory, Hyper-V, SQL Server, PowerShell

    • Domänmiljö med domänkontrollant, DNS och DHCP samt användare, grupper och OU-struktur.
    • Grupprinciper för säkerhet och klientinställningar, och filserver med delade mappar och NTFS-behörigheter som styrs via grupper.
    • Hyper-V med virtuella switchar och nätverk, checkpoints och export och import av virtuella maskiner.
    • Installation och drift av applikationer på servrarna och distribution av appar till klienter med Intune.
    • Felsökning av incidenter och driftstörningar i skolans labbmiljöer, till exempel tjänster som inte startar, nätverksproblem och grupprinciper som inte slår igenom.
    • Patchning, backup och provad återställning, SQL Server i bruk och PowerShell-skript som automatiserar administrationen.

  • Boendeportalen

    Azure Container Apps, Entra External ID, Cosmos DB, Logic Apps, Microsoft Graph

    Portal för hyresvärdar där hyresgäster loggar in med engångskod, gör felanmälan, ser sitt kontrakt och ställer sig i parkeringskö, med en separat vy för personalen. Databasen nås bara via privat slutpunkt, och allt driftsätts med ARM-mallar och ett PowerShell-skript.

    Läs mer och se bilder

  • LookFirst

    Öppen källkod, Go, VS Code, GitHub Actions

    Verktyg och VS Code-tillägg som visar vad Terraform-, Bicep-, ARM-, CloudFormation- och skriptkod skapar i Azure och AWS innan den körs, och pekar ut säkerhetsrisker som öppna portar och publik lagring. Publicerat på Visual Studio Marketplace och släpps via GitHub Actions.

    Läs mer och se bilder

  • Cleanroom

    Öppen källkod, Go, Bicep, Azure SQL, Azure Relay

    Ett kommando bygger en Azure SQL-databas utan publik åtkomst, bara nåbar via privat slutpunkt. Utvecklaren kommer åt den genom en tunnel via Azure Relay med sin vanliga inloggning, utan lösenord. Ett annat kommando river allt.

    Öppen källkod, Microsoft Graph, Azure Resource Manager

    Verktyg som med enbart läsbehörighet varnar när lösenord och certifikat för appar i Entra ID snart går ut, och hittar appar utan ägare.
