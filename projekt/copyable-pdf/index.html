Markdown to Copyable PDF

Ett VS Code-tillägg som gör PDF av Markdown.

Installera i VS Code Koden

Varför

De flesta verktyg som gör PDF av Markdown bryter långa kommandon vid sidkanten. Kopierar man kommandot följer radbrytningen med, och terminalen kör halva kommandot.

Jag behövde PDF:er där kommandona går att kopiera och klistra in utan att något går sönder, så jag byggde ett tillägg där varje kodrad går att kopiera exakt som den står.

Bilder

Så fungerar den

  1. Delar långa kommandon rätt. Backtick för PowerShell, backslash för bash och ^ för cmd, före parametrarna så att varje parameter stannar ihop med sitt värde.
  2. Krymper det som inte går att dela. YAML, JSON och långa citat skrivs ut i lagom mindre stil så att varje rad får plats.
  3. Varnar medan du skriver. Rader som kommer att delas eller inte får plats markeras direkt i editorn.
  4. Kontrollerar efteråt. Den färdiga PDF:en läses med PDFium, samma motor som Edge och Chrome använder när man kopierar, och rader som inte går att kopiera hela markeras.
  5. Mermaid utan internet. Diagrammen ritas med en kopia som följer med tillägget.
  6. Signerade versioner. Finns på Visual Studio Marketplace och som signerade filer på GitHub.
