  1. 01 / 07Öppen kod

    LookFirst

    Visar vad AI-skriven kod gör innan du kör den.

    Många klistrar in kod från en AI utan att riktigt veta vad den skapar. LookFirst läser koden och visar i ordning vad som kommer att byggas, hur delarna hänger ihop och var säkerhetsluckorna finns, till exempel öppna portar eller nycklar i klartext. Varje råd länkar till Microsofts eller Amazons egna säkerhetsregler.

    Finns som VS Code-tillägg, kommandorad, GitHub Action och webbsida. Releaserna är signerade.

    Go / VS Code / Terraform / Bicep / CloudFormation / GitHub Actions

    Koden Prova på webben

  2. 02 / 07Privat kod

    Boendeportalen

    En portal för hyresvärdar och bostadsrättsföreningar.

    De boende gör felanmälan, bokar tvättid, betalar avier och läser dokument. Personalen har en egen portal med ärenden, bostadskö, roller och behörigheter. Varje kund får en egen Azure-miljö med sin egen inloggning, sina färger och sin logga.

    API och webhooks för andra system, revisionslogg och GDPR-export. Allt sätts upp med skript och ARM-mallar.

    Python / Container Apps / Cosmos DB / Key Vault / Entra External ID

    Visas gärna på förfrågan

  3. 03 / 07Öppen kod

    Cleanroom

    En tillfällig, privat databas i Azure på runt fem minuter.

    Ett kommando bygger en Azure SQL-databas som inte syns på internet alls. Utvecklaren kommer åt den genom en tunnel via Azure Relay med sin vanliga inloggning, utan lösenord eller nycklar. När jobbet är klart river ett annat kommando allt.

    Go / Bicep / Azure SQL / Azure Relay / privata nätverk

    Koden

  4. 04 / 07Öppen kod

    Bäst före

    Visar vad i Microsoft-miljön som snart slutar fungera.

    Appnycklar och certifikat som går ut, appar som ingen äger längre och kopplingar i Logic Apps som hänger på en enda person. Verktyget behöver bara läsbehörighet. När jag körde det mot min egen tenant hittade det tre appar utan ägare.

    Python / Microsoft Graph / Entra ID / Logic Apps

    Koden

  5. 05 / 07Labbmiljö

    Microsoft 365-labb

    En egen tenant där jag övar på det som företag faktiskt använder.

    Lokalt AD synkas till Entra med Cloud Sync. Jag har satt upp Conditional Access, PIM, åtkomstpaket och flöden för nyanställda och de som slutar. Datorerna installeras med Autopilot och får BitLocker, LAPS och krav på godkänd enhet i Intune.

    I Purview har jag känslighetsetiketter med kryptering och DLP för personnummer.

    Entra ID / Intune / Autopilot / SharePoint / Purview / PowerShell

  6. 06 / 07Privat kod

    Swapp

    En Android-app för tiden i sociala medier.

    Appen räknar hur länge du har varit i sociala appar och visar vad samma tid hade räckt till, till exempel en promenad eller ett kapitel i en bok. Den har dagsmål, en mjuk pausruta och en widget.

    Appen saknar behörighet till internet helt, så ingenting kan lämna telefonen.

    Kotlin / Jetpack Compose / Android

    Visas gärna på förfrågan

  7. 07 / 07Öppen kod

    Markdown to Copyable PDF

    Ett VS Code-tillägg som gör PDF av Markdown.

    Jag behövde PDF:er där kommandona går att kopiera och klistra in utan att något går sönder. Tillägget delar långa kommandon på rätt sätt för PowerShell och bash, ritar Mermaid-diagram utan internet och kontrollerar efteråt att texten i PDF:en stämmer.

    JavaScript / VS Code / Python
