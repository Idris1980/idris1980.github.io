Cleanroom

A temporary, private database in Azure in about five minutes.

Code

Why

A developer who needs a real database to test against usually has two bad options: open a database to the internet "just for a while", or wait days for someone to set up an environment, a VPN and permissions.

Cleanroom gives every developer a private sandbox they can break freely and throw away when the work is done.

How it works

  1. cleanroom up creates an isolated Azure environment with a SQL database that can't be reached from the internet. It's ready in about five minutes.
  2. cleanroom connect opens a private tunnel from your machine to the database over Azure Relay. Both sides dial out, so no port has to be opened.
  3. No passwords or keys. You sign in with your normal Entra ID account.
  4. Private network. The database is only reachable through a private endpoint, with public access turned off.
  5. cleanroom down removes everything again, including the cost.

Built with

  • Go
  • Bicep
  • Azure SQL
  • Azure Relay
  • private networking
