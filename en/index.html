LookFirst

Open source

Shows what AI-written code does before you run it.

A lot of people paste code from an AI without really knowing what it creates. LookFirst reads the code and shows, step by step, what will be built, how the parts connect and where the security gaps are, such as open ports or keys in plain text. Every piece of advice links to Microsoft's or Amazon's own security guidance.

Available as a VS Code extension, a command-line tool, a GitHub Action and a web page. Reads Terraform, Bicep, ARM, CloudFormation, Docker Compose, Kubernetes and scripts using az, aws and PowerShell. Releases are signed.

  • Go
  • VS Code
  • Azure
  • AWS
  • GitHub Actions
  • Security

Resident Portal

Private code

A portal for landlords and housing cooperatives.

Residents report faults, book laundry times, pay invoices and read documents. Staff have their own portal with cases, a housing queue, roles and permissions. Every customer gets a separate Azure environment with its own sign-in, colours and logo.

Built on Container Apps, Cosmos DB, Key Vault and Entra External ID. Has an API and webhooks for other systems, an audit log and GDPR export. Everything is deployed with scripts and ARM templates.

  • Python
  • Azure Container Apps
  • Cosmos DB
  • Entra ID
  • ARM

Cleanroom

Open source

A temporary, private database in Azure in about five minutes.

One command builds an Azure SQL database that isn't reachable from the internet at all. The developer gets in through a tunnel over Azure Relay using their normal sign-in, with no passwords or keys. When the work is done, another command tears everything down.

  • Go
  • Bicep
  • Azure SQL
  • Azure Relay
  • Private networking

Open source

Shows what in a Microsoft environment is about to stop working.

App secrets and certificates that are expiring, apps nobody owns anymore, and Logic Apps connections that depend on a single person. The tool only needs read access. When I ran it against my own tenant, it found three apps without an owner.

Microsoft 365 lab

Lab environment

My own tenant, where I practise what companies actually use.

An on-premises AD syncs to Entra with Cloud Sync. I've set up Conditional Access, PIM, access packages and joiner and leaver workflows. Computers are installed with Autopilot and get BitLocker, LAPS and compliance requirements in Intune.
